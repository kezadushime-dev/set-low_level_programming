# 0x03. C - Debugging

This project contains C programs used to practice debugging and fixing errors.

## Tasks

- **0. Multiple mains:** Test whether an integer is positive, negative, or zero.
- **1. Like, comment, subscribe:** Fix an infinite loop.
- **2. 0 > 972?:** Find the largest of three integers.
- **3. Leap year:** Calculate the day of the year and the remaining days.

## Compilation

The programs are compiled using GCC with the following options:

```bash
gcc -Wall -Werror -Wextra -pedantic -std=gnu89
```
