# 0x07. C - Even more pointers, arrays and strings

C implementations for memory operations, string scanning/search, 2D chessboard output, and matrix diagonal sums following Betty style and `-std=gnu89`.

## Files
- `main.h` - Function prototypes
- `0-memset.c` - Fills memory with a constant byte (`_memset`)
- `1-memcpy.c` - Copies memory area (`_memcpy`)
- `2-strchr.c` - Locates a character in a string (`_strchr`)
- `3-strspn.c` - Gets the length of a prefix substring (`_strspn`)
- `4-strpbrk.c` - Searches a string for any set of bytes (`_strpbrk`)
- `5-strstr.c` - Locates a substring (`_strstr`)
- `6-print_chessboard.c` - Prints an 8x8 chessboard (`print_chessboard`)
- `7-print_diagsums.c` - Prints diagonal sums of a square matrix (`print_diagsums`)
