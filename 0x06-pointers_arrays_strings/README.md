# 0x06. C - More pointers, arrays and strings

C implementations for string manipulation, comparison, array reversal, capitalization, and 1337 encoding following Betty style and `-std=gnu89`.

## Files
- `main.h` - Function prototypes
- `0-strcat.c` - Concatenates two strings (`_strcat`)
- `1-strncat.c` - Concatenates up to `n` bytes from `src` (`_strncat`)
- `2-strncpy.c` - Copies up to `n` bytes (`_strncpy`)
- `3-strcmp.c` - Compares two strings (`_strcmp`)
- `4-rev_array.c` - Reverses an integer array (`reverse_array`)
- `5-string_toupper.c` - Converts lowercase letters to uppercase (`string_toupper`)
- `6-cap_string.c` - Capitalizes words based on separators (`cap_string`)
- `7-leet.c` - Encodes letters into 1337 (`leet`)
